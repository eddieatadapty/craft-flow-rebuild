# Craft Growth Audit

**Live → https://eddieatadapty.github.io/craft-flow-rebuild/**

Five ideas to turn more Craft users into subscribers, each built into a clickable version of Craft's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they’ll use Craft for, then say it back | +10–20% CR to purchase |
| 02 | Let them try Craft before the email code | +5–10% CR to purchase · ARPU +10–17% |
| 03 | Put Plus where the tutorial ends | +10–20% CR to purchase |
| 04 | Say the yearly saving out loud, next to the proof | +10–15% ARPU · CR +5–15% |
| 05 | Offer monthly to people who close | +5–10% ARPU, from people who said no |

Every price, rating and feature comes from Craft's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Craft. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
